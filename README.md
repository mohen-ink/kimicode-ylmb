# Kimi Code 用量面板 (Kimi Code Usage Panel) v3.4.3

实时记录并可视化 **Kimi Code Agent** 的每一次模型调用用量，把**模型能力管理**（识图 / 深度思考 / 工具调用 / 强度档位）、**模式滑杆**与**官方配额监控**整合进同一侧栏卡片，另附**手机远程连接**（内网 / Cloudflare Quick Tunnel / 自建中继，扫码或复制链接配对，预览功能）。用量采集零外部依赖、纯本地进行；外网连接需要经明确同意安装单独的 Cloudflare 组件，自建中继需自备服务器。界面直接渲染在桌面端内。

---

## 安装

### 方式一：从插件仓库安装（推荐）

1. 打开 **设置 → 插件**，点**安装三方插件**；
2. 在输入框粘贴本仓库地址：

   ```text
   https://github.com/ziyiclouds-blip/kimicode-ylmb
   ```

3. 确认后等待安装完成，侧栏即出现「Kimi Code 用量」卡片。

该入口支持 **https zip 链接、GitHub 仓库地址或本地目录路径**。

### 方式二：会话内命令安装

```text
/plugins install <仓库地址或本目录路径>
/plugins reload
```

### 环境要求

Windows + Python ≥3.8（`py -3` 或 `python` 在 PATH 即可）。找不到 Python 时，侧栏会显示一张提示卡片引导安装，不会静默空白。外网 CF 隧道另限 Windows AMD64。

安装后插件随会话心跳自动拉起后台用量服务，**无需任何桌面脚本或开机自启**。用量服务自动运行不等于手机连接自动开启——手机连接必须由你显式开启。

## 卸载

1. 点击侧栏卡片标题或「📊 面板」，在面板右上角点**卸载**；
2. 确认后弹出命令行窗口显示进度，它会结束插件进程、清理侧边栏注入，并删除用量数据目录和插件目录；
3. 窗口结束后，到 **设置 → 插件 → 删除插件**；
4. 重启 Kimi Code，侧栏卡片即消失。

## 使用

### 侧栏卡片

常驻显示，每 2 秒刷新：

- 今日 / 昨日 / 本周 / 本月 / 累计 **Token 消耗与成本**
- **消耗速率**（最近 60 分钟实算，而非当日平均）
- **缓存命中率**（缓存读取 ÷ 总输入）与**实时输出速度**（最近 120s 实算 t/s）
- **当前会话模型行**：`⚡ alias 简写 · 思:effort · 工√ · 子代理名`
- **官方配额行**：周 / 5 小时窗口已用 %，配速 >1.3× 标红并提示预计耗尽时间（Free 账号无配额数据时隐藏）
- **本会话行**：当前会话 token / 调用 / 缓存率
- 近 7 天微缩走势条，今日 / 累计模型明细可切换；折叠状态会被记住
- 鼠标悬停名称弹详情浮层（模型 / 会话完整信息）

### 全屏报表

点卡片标题或「📊 面板」打开（内嵌渲染，无 iframe）：

- 波浪面积图 + 调用量柱形，可在**今日逐小时 / 本周 7 天 / 本月 30 天**之间切换
- 模型份额表、会话 Top 8、30 天明细表
- 深浅主题切换

### 模型与供应商管理

侧栏点 `⚙` 打开管理器。

**新增模型**：先在「供应商」中新增连接，再点「新增模型」，选择供应商后手动点「探测模型列表」（弹窗不会自动探测）。列表支持搜索及「全部 / GPT / Claude / Gemini / Qwen / GLM / Deepseek / Kimi / 其他」筛选；已添加的本地模型统一排在末尾，配置中已有但上游未返回的模型也会保留显示。新模型别名自动加供应商前缀（如供应商 `CPA` 的 `devin/claude-opus-5-5` 生成 `CPA/devin/claude-opus-5-5`）。

每行右侧是 `+ / −` 与铅笔按钮：未添加的点 `+` 选中、`−` 取消；已添加的显示禁用的 `−`。**这个页面不删除已有模型**——删除在 `⚙` 首页的「模型」页面，每张卡片有删除按钮，确认后立即删除。

**新建模型默认值**：识图、思考、工具调用全开，上下文 `1M`，五档强度 `low / medium / high / xhigh / max`，默认 `high`。详情可改，并提供 `256k / 1M` 上下文预设及自定义。这些只是本地声明，不代表上游实际支持。

**供应商**：编辑协议与 API 地址，密钥输入默认遮罩。已有密钥不回显——`keep` 保留旧值、`replace` 写入新值、`clear` 清除。已绑定 `api_key_env` 时需先手动解除绑定才能替换。

**保存行为**：表单与批量草稿都点「保存」才写入，取消不写；保存成功后执行 `/reload` 加载。写入采用原子替换，不生成配置备份，不依赖 Kimi CLI。草稿打开后若配置被其他会话或外部工具改动，保存会拒绝覆盖，需重新载入。

**删除保护**：托管模型、默认模型，以及被子代理模型池或模式滑杆预设 / 恢复快照引用的模型不能删除，需先解除引用。

**探测协议**：支持 OpenAI、OpenAI Responses、Kimi 的 Bearer `/models`，Anthropic 与 Google GenAI 的各自鉴权与分页；Vertex / OAuth 暂不支持探测，可用手动添加。不跟随重定向，不向其它地址发送密钥。

本版不提供供应商删除、重命名、复制、原始 TOML 编辑与备份恢复界面。

### 手机远程连接（预览）

侧栏「手机」浮层顶部是三段模式切换：**内网**、**CF 隧道**、**中继服务器**。打开浮层不会自动安装组件或开启连接。

| 模式 | 链路 | 适合场景 |
|---|---|---|
| 内网 | 手机直连电脑局域网 IP | 同一可信 Wi-Fi，最简单 |
| CF 隧道 | Cloudflare Quick Tunnel | 没有 VPS，缺点是地址随机、速度看运气 |
| 中继服务器 | 你自己的 VPS 转发 | 想要固定地址、自己掌控链路；见 [自建中继搭建教程](docs/自建中继服务器-搭建教程.md) |

**CF 隧道步骤**：

1. 打开「手机」浮层，勾选下载同意并点安装连接组件（固定 `cloudflared 2026.9.3`，首次可能需 2–3 分钟，**安装中勿重复点击**）；安装失败先检查到官方发布站点的网络，再显式重试。
2. 勾选第三方中继同意并开启：**Cloudflare 在 TLS 终止处可见经过的会话内容**，并非端到端加密。安装同意不等于中继同意。
3. 等隧道就绪后，浮层显示配对链接与二维码。手机用**系统浏览器**扫码或打开链接（微信等内置浏览器请切到系统浏览器）。
4. 配第二台手机：点「生成新二维码」重新扫码（旧码作废，已连设备不受影响）。
5. 撤销：回浮层点「停止」，吊销配对码、已配会话、WebSocket 与隧道。

**中继服务器模式**：模式切到「中继服务器」→ 在浮层里填**服务器地址 / 隧道端口 / 公网端口 / 连接密钥**并保存 → 点「开启中继连接」。四个字段必须与服务端启动参数一致，部署细节见 [自建中继搭建教程](docs/自建中继服务器-搭建教程.md)。

几点须知：

- **配对 = 控制授权**：手机可查看会话，并发 prompt 驱动电脑 Agent（含读写文件、执行命令）。请勿分享链接或二维码。
- **配对码 10 分钟一次性**：只出现在 URL fragment，成功兑换一台设备即销毁；最多 8 台设备。
- **电脑须一直开机**且服务运行；关机或服务异常会中断连接。**关闭浮层不会断开连接**。
- 开启期间模式切换块锁定为当前模式，需先停止才能切换。
- 手机端使用 Kimi 原生手机 SPA，桥只负责配对与受限转发，另外提供只读的 `/mobile/usage` 用量页。

**服务限制**：Quick Tunnel 是临时随机地址，停止或重开后变化，不承诺永久 URL 也无 SLA。电脑向 Cloudflare 发起出站连接需网络允许 **7844/UDP（QUIC）或 7844/TCP**，不需要路由器端口映射，不会自动改防火墙。

**安全边界**：桥只放行精确 method + route 的受限会话面，机器级管理与未知路由默认拒绝；文件上传体上限 32 MiB；凭据不向手机返回真实值，日志与状态不含原始凭据。自建中继为**明文传输**（`ws://` / `http://`），配对码、Cookie、会话与文件内容经 VPS 时不保密，仅建议在自控服务器、临时联调场景使用。

### 更新

面板**不会自动更新**。点面板头部「更新」按钮才会检查——有新版本时弹窗显示发布时间与更新内容，**需你点击确认**才下载、覆盖插件文件并自动重启服务（用量数据、价格配置不受影响）。会话里也可用 `/update`。另有每日静默提醒：有新版本只在「更新」/「面板」按钮上亮红点，不弹窗，可点头部「更新提醒：开/关」关闭。更新后界面若提示「刷新界面」，照做即可。

## 计费单价

按 Kimi K3 官方价折算（元 / 百万 Token）：输入 `20`、缓存读 `2`、输出 `100`，缓存创建按输入价。常量在 `scripts/scanner.py` 顶部，可按需调整。
