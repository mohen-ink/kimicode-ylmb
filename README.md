# Kimi Code 用量面板 (Kimi Code Usage Panel) v3.4.9

实时记录并可视化 **Kimi Code Agent** 的每一次模型调用用量，把**模型能力管理**（识图 / 深度思考 / 工具调用 / 强度档位）、**模式滑杆**与**官方配额监控**整合进同一侧栏卡片，另附**手机远程连接**（内网 / Cloudflare Quick Tunnel / 自建中继，扫码或复制链接配对，预览功能）。用量采集零外部依赖、纯本地进行；外网连接需要经明确同意安装单独的 Cloudflare 组件，自建中继需自备服务器。界面直接渲染在桌面端内。

---

## 安装

### 方式一：从插件仓库安装（推荐）

1. 打开 **设置 → 插件**，点**安装三方插件**；
2. 在输入框粘贴本仓库地址：

   ```text
   https://github.com/mohen-ink/kimicode-ylmb
   ```

3. 确认后等待安装完成，侧栏即出现「Kimi Code 用量」卡片。

该入口支持 **https zip 链接、GitHub 仓库地址或本地目录路径**。

### 方式二：会话内命令安装

```text
/plugins install <仓库地址或本目录路径>
/plugins reload
```

### 环境要求

Windows + Python ≥3.8（`py -3` 或 `python` 在 PATH 即可）。找不到 Python 时，侧栏会显示一张提示卡片引导安装，不会静默空白。外网 CF 隧道另限 Windows AMD64。

安装后插件随会话心跳自动拉起后台用量服务，**无需任何桌面脚本或开机自启**。用量服务自动运行不等于手机连接自动开启——手机连接必须由你显式开启。

## 卸载

1. 点击侧栏卡片标题或「📊 面板」，在面板右上角点**卸载**；
2. 确认后弹出命令行窗口显示进度，它会结束插件进程、清理侧边栏注入，并删除用量数据目录和插件目录；
3. 窗口结束后，到 **设置 → 插件 → 删除插件**；
4. 重启 Kimi Code，侧栏卡片即消失。

## 使用

### 侧栏卡片

常驻显示，每 2 秒刷新：

- 今日 / 昨日 / 本周 / 本月 / 累计 **Token 消耗与成本**
- **消耗速率**（最近 60 分钟实算，而非当日平均）
- **缓存命中率**（缓存读取 ÷ 总输入）与**实时输出速度**（最近 120s 实算 t/s）
- **当前会话模型行**：`⚡ alias 简写 · 思:effort · 工√ · 子代理名`
- **官方配额行**：周 / 5 小时窗口已用 %，配速 >1.3× 标红并提示预计耗尽时间（Free 账号无配额数据时隐藏）
- **本会话行**：当前会话 token / 调用 / 缓存率
- 近 7 天微缩走势条，今日 / 累计模型明细可切换；折叠状态会被记住
- 鼠标悬停名称弹详情浮层（模型 / 会话完整信息）

### 全屏报表

点卡片标题或「📊 面板」打开（内嵌渲染，无 iframe）：

- 波浪面积图 + 调用量柱形，可在**今日逐小时 / 本周 7 天 / 本月 30 天**之间切换
- 模型份额表、会话 Top 8、30 天明细表
- 深浅主题切换

### 挂件开关

打开侧栏「📊 面板」，点击顶部「更新提醒」左侧的**挂件：开 / 关**按钮切换，默认开启，设置持久化在本机 `usage-dashboard/settings.json`，重启后保留。

- 关闭后，桌面侧栏隐藏整个模式栏，手机面板隐藏「模式」标签与档位编辑入口；已打开的页面会轮询同步状态。
- 挂件提示 hook、子代理调用守卫、桌面/手机模型锁定和后台锁档守护同时停用；关闭期间不能从旧界面切档或改写档位。
- 用量采集、模型/供应商管理、计价和手机连接不受影响。
- 已有档位、快照和锁定记录不删除；关闭不会自动回滚 `config.toml` 或改写当前会话模型，重新开启恢复有效锁档。宿主原生子代理行为仍由当前宿主配置决定。

### 档位作用域

开启挂件后，模式滑杆区分「全局」与「本对话」：本对话选档只写该对话的主模型与挂件白名单，并自动把所需挂件并入宿主共享目录；全局切档只影响跟随全局的对话，已有独立设置的对话保留原档位。要让当前对话恢复跟随全局，点面板里的**本对话跟随全局**并确认；仅切换到「全局」视图不会解除独立设置。保存或重置档位预设不会改动已应用的对话，需重新选档才生效。

关掉挂件开关后，目录同步、跟随全局、档位写入一并停用，但已有记录不删除。

### 设置中心

侧栏点 `⚙` 打开设置。左侧为模型、供应商、MCP 服务器与技能，四个板块均支持搜索。编辑和查看使用同一详情区；窄窗口以返回按钮回到列表，搜索和列表位置保留。Esc 依次退出确认、详情和设置。

**新增模型**：点击「新增模型」，选择供应商后手动点击「获取模型列表」，勾选模型并点击「添加 N 个模型」。已有模型只显示「已添加」，不在此处编辑或删除。没有供应商时可直接新建，保存后继续添加模型；列表获取失败时可手动添加。别名自动加供应商前缀。

**模型列表**：展示名称、默认/使用中状态、能力和强度摘要。能力、上下文和思考档位在「编辑」中修改；计价、设为默认和删除位于「⋯」。不能删除时菜单直接说明原因。计价使用统一详情区，「使用默认计价」也需点击保存才提交。

**新建模型默认值**：识图、思考、工具调用全开，上下文 `1M`，五档强度 `low / medium / high / xhigh / max`，默认 `high`。详情提供 `256k / 1M` 预设及自定义。这些是本地声明，不代表上游实际支持。

**供应商**：编辑接口协议与 API 地址，密钥输入默认遮罩。已有密钥不回显；默认保留，明确选择更换或移除后点击保存。已绑定 `api_key_env` 时需先解除绑定才能替换。供应商列表可直接进入该供应商的模型添加流程。

**保存行为**：列表独立操作自动保存；详情表单点击「保存」才提交，取消不写。离开有未保存修改的详情时统一确认。保存失败保留输入；模型、供应商与 MCP 配置冲突拒绝覆盖，可明确放弃输入后载入最新配置。模型与供应商保存后在会话中 `/reload` 加载；MCP 在新会话或重连后加载。设为默认不切换当前对话。

**MCP 与技能**：MCP 提供启用、连接编辑与删除，超时和工具过滤收进高级设置。技能按来源展示，仅用户级可编辑；「自动调用」关闭后仍可手动触发。技能正文支持展开编辑，删除会确认移除整个目录。

**删除保护**：托管模型、默认模型，以及被子代理模型池或模式滑杆预设 / 恢复快照引用的模型不能删除，需先解除引用。

**从 models.dev 同步价格**：工具栏「⋯ → 同步参考价格」拉取公开目录（12 小时缓存），在详情区显示匹配结果、来源厂商及换算后的价格。选择并确认后更新估算单价；按次计价模型自动跳过。参考价不代表供应商实际收费。

匹配只看模型 id 本身（不含供应商前缀），且**只取第一方厂商的官方牌价**——openrouter、deepinfra 等转售商的价格（常有大幅折扣）不参与；候选条目还须属于该厂商自家模型族（阿里云上代挂的 kimi/deepseek 按平台价计，不算）。型号数字必须完全一致才算同一模型（`v4.1` 不会错配到 `v4`）；官方目录 id 不带版本号时按显示名匹配（如 DeepSeek 官方 `deepseek-flash` = "DeepSeek V4.1 Flash"）。汇率默认 7.1，详情区可改后重新匹配。个别匹配不理想时可取消勾选或在模型计价设置中手动覆盖。

**探测协议**：支持 OpenAI、OpenAI Responses、Kimi 的 Bearer `/models`，Anthropic 与 Google GenAI 的各自鉴权与分页；Vertex / OAuth 暂不支持探测，可用手动添加。不跟随重定向，不向其它地址发送密钥。

供应商卡片的「⋯ → 删除供应商」确认后立即保存：会连同该供应商下的全部模型一起原子删除，确认框与菜单会写明模型数量。删除不受引用限制，默认模型、子代理模型池、模式档位/锁定/恢复快照中指向已删模型的引用会被自动清理；托管/OAuth 供应商同样可删。删除会移除本地连接及认证配置，不会清除系统环境变量。

本版不提供供应商重命名、复制、原始 TOML 编辑与备份恢复界面。

### 手机远程连接（预览）

侧栏「手机」浮层顶部是三段模式切换：**内网**、**CF 隧道**、**中继服务器**。打开浮层不会自动安装组件或开启连接。

| 模式 | 链路 | 适合场景 |
|---|---|---|
| 内网 | 手机直连电脑局域网 IP | 同一可信 Wi-Fi，最简单 |
| CF 隧道 | Cloudflare Quick Tunnel | 没有 VPS，缺点是地址随机、速度看运气 |
| 中继服务器 | 你自己的 VPS 转发 | 想要固定地址、自己掌控链路；见 [自建中继搭建教程](docs/自建中继服务器-搭建教程.md) |

**CF 隧道步骤**：

1. 打开「手机」浮层，勾选下载同意并点安装连接组件（固定 `cloudflared 2026.9.3`，首次可能需 2–3 分钟，**安装中勿重复点击**）；安装失败先检查到官方发布站点的网络，再显式重试。
2. 勾选第三方中继同意并开启：**Cloudflare 在 TLS 终止处可见经过的会话内容**，并非端到端加密。安装同意不等于中继同意。
3. 等隧道就绪后，浮层显示配对链接与二维码。手机用**系统浏览器**扫码或打开链接（微信等内置浏览器请切到系统浏览器）。
4. 第二台手机可重复扫描密码二维码；未设密码时点「生成新二维码」换发一次性码（已连设备不受影响）。
5. 撤销：回浮层点「停止」，吊销配对码、已配会话、WebSocket 与隧道。

**中继服务器模式**：模式切到「中继服务器」→ 填**服务器地址（含端口）和准入密钥**并保存 → 注册账号或登录已有账号并绑定本机 →「开启中继连接」。服务器只监听一个 HTTP/WS 端口。手机直接访问服务器地址可手动登录、选择账号下的电脑；扫码则读取原始账号密码及本机设备 ID，自动走同一个正常登录接口并进入本机。二维码可长期重复使用，不另设扫码凭据。部署与升级见 [自建中继搭建教程](docs/自建中继服务器-搭建教程.md)。

几点须知：

- **配对 = 控制授权**：手机可查看会话，并发 prompt 驱动电脑 Agent（含读写文件、执行命令）。请勿分享链接或二维码。
- **内网/CF 配对**：本机密码最多 128 字符，`#pw=` 二维码可重复使用；未设密码时使用 10 分钟一次性配对码，最多 8 台手机，登录七天有效。
- **中继账号登录**：原始账号密码及设备凭据持久保存在本机；二维码包含原始账号密码。服务器保存密码慢哈希并校验手机登录，登录七天有效、每账号最多 8 个手机会话。修改账号密码注销所有手机登录，须在各电脑用新密码重新登录绑定以更新二维码；仅刷新二维码不撤销旧码。
- **自动恢复**：开启内网或中继后，重开 Kimi 自动恢复连接；CF 隧道仍需手动开启。点击「停止」断开控制并取消自动恢复，中继保留账号绑定及服务器登录态；解除绑定才撤销设备凭据。服务器和本机必须同步升级到单端口账号协议。
- **电脑须一直开机**且服务运行；关机或服务异常会中断连接。**关闭浮层不会断开连接**。
- 开启期间模式切换块锁定为当前模式，需先停止才能切换。
- 手机端保留 Kimi 原生聊天 SPA，点击悬浮「面板」进入手机用量面板；悬浮入口可拖动并按当前站点记位，长按可复位。打开面板后可拖动顶部标题调整高度并记住位置；`/mobile/usage` 也可单独打开。面板有触控模式滑杆、档位编辑/锁定/恢复、今日至累计用量与趋势、模型/供应商和计价管理；重复选择当前档可重新同步。本对话选档会自动注册所需挂件到共享宿主目录，但只允许该对话调用选定挂件；全局切档仅同步跟随全局的对话，独立锁定的对话保留原档位。点击「本对话跟随全局」会确认解除当前对话独立设置和锁定，不影响其它独立对话。锁定分别校准全局默认配置和各自独立对话模型，休眠会话不被后台强制唤醒；手机桥会拒绝绕过锁档修改主模型，创建主会话使用锁档模型，发送消息前先核对并校准目标会话，校准失败不发送。子代理创建保留档位配置的独立挂件模型。操作只走配对后的固定白名单接口。远程卸载、插件更新和手机连接开停仍需在电脑端操作；明文内网/自建中继禁止提交新供应商密钥。挂件开关关闭时上述档位相关能力整体停用。

**服务限制**：Quick Tunnel 是临时随机地址，停止或重开后变化，不承诺永久 URL 也无 SLA。电脑向 Cloudflare 发起出站连接需网络允许 **7844/UDP（QUIC）或 7844/TCP**，不需要路由器端口映射，不会自动改防火墙。

**安全边界**：桥只放行精确 method + route 的受限会话面，机器级管理与未知路由默认拒绝；文件上传体上限 32 MiB；真实本机 `server.token` 不向手机返回；中继二维码按设计包含原始账号密码，本机二维码状态也包含该链接，日志不得记录这些值。自建中继为**明文传输**（`ws://` / `http://`），配对码、Cookie、会话与文件内容经 VPS 时不保密，仅建议在自控服务器、临时联调场景使用。

### 更新

面板**不会自动更新**。此安装目录含手机面板本地适配，清单标记 `localPreview`，面板头部「更新」及 `/update` 会拒绝直接覆盖；后续仓库版本须先合并本地适配再解除预览标记，以免丢失手机端功能。未做本地适配的正式安装，点「更新」才检查并确认下载；更新后若提示「刷新界面」，照做即可。

## 计费单价

按 Kimi K3 官方价折算（元 / 百万 Token）：输入 `20`、缓存读 `2`、输出 `100`，缓存创建按输入价。常量在 `scripts/scanner.py` 顶部，可按需调整。
