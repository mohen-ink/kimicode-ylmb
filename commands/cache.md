请分析 Kimi Code 的缓存命中率与成本结构。

从用量数据中提取：
1. **总体缓存命中率**：`cache.pct`（缓存读取 Token ÷ 总输入 Token）
2. **分模型缓存率**：哪些模型命中率偏低
3. **分会话缓存率**：哪些会话反复重建上下文
4. **成本拆解**：未缓存输入、缓存读取、输出三部分各占成本比例

优化建议方向：
- 缓存率 < 40%：上下文被反复灌入，建议减少无谓的重复读取与频繁会话切换
- 单会话缓存率显著低于均值：该会话可能存在大量一次性大文件读取
- 输出占比过高：适合改用更精简的输出策略

参数：$ARGUMENTS
