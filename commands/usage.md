---
name: usage
description: 查看 Kimi Code 当前 Token 用量、成本与调用统计
---

请读取 Kimi Code 用量数据并汇报。

数据文件：运行中服务的 `/kimi-usage.json`，或本地应用资源目录中的 `kimi-usage.json`。

汇报内容：
1. **今日与累计**：Token 总量、估算成本、调用次数、输入 / 输出拆分
2. **健康指标**：缓存命中率、今日消耗速率、当前输出速度与活跃模型
3. **模型分布**：今日与累计两档，各模型 Token、调用次数、缓存率、成本、占比
4. **会话排行**：消耗最高的若干会话
5. **异常提示**：缓存率过低、单会话占比过高、速率突增等

参数：$ARGUMENTS
