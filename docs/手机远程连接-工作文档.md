# 手机远程连接 — 工作文档

> 适用范围：Kimi Code 用量面板（插件 `kimi-code-usage`）的**手机远程连接**子功能。
> 当前版本：**v3.4.0（2026-10-09）**。手机远程连接**仍是预览功能**，公网真机验收尚未完成。
> 本文描述该功能的实际形态与已核实/未核实边界。合并与部署回滚见[手机远程连接-合并文档.md](手机远程连接-合并文档.md)；未验收清单见[手机远程连接-最终工作文档-20261007.md](手机远程连接-最终工作文档-20261007.md) §7。

---

## 1. 目标与形态

**目标**：在桌面端侧栏面板中，让用户用手机浏览器远程使用当前电脑上的 Kimi Code Agent 会话——看流式回复、发 prompt、审批、回答提问、上传文件、归档/删除/导出会话——同时保持严格的安全边界。

**当前形态**：

- 侧栏「手机」浮层提供**三种连接模式**：**内网**（可信局域网明文 HTTP）、**CF 隧道**（Cloudflare Quick Tunnel）、**自建中继**（用户自己的公网服务器）。
- 三种模式共用同一个手机桥与配对层；开哪种由浮层切换块决定，桥开启期间锁定为当前模式。
- 手机端得到的是 **Kimi 原生手机单页应用**，桥只负责把配对后的 HTTP/WebSocket 流量转发给本机桌面实例并注入真实凭据——不维护第二套界面。
- 手机桥运行在**独立的 detached worker 进程**中：用量后台退出或重启只 detach，桥会话、隧道、配对在 worker 内存中继续存活。
- 提供**手机只读用量页**：已配对设备可通过同源入口查看用量数据。

**明确不承诺**：

- **不承诺永久公网地址**：CF 隧道使用临时随机地址，停止或重开后变化，无可用性 SLA；自建中继地址固定，但稳定性取决于用户自己的服务器。
- **不是端到端加密**：CF 隧道在 TLS 终止处可见经过的会话内容；**自建中继第一阶段为明文**（`ws://` / `http://`，无 TLS），配对码、Cookie、会话与文件内容经 VPS 时不可保密。
- **不是 P2P**：手机流量经第三方中继（Cloudflare 或用户自建服务器）转发。

## 2. 组件与依赖

| 组件 | 来源 | 许可证 | 校验方式 |
|---|---|---|---|
| 插件本体 | 本仓库 | MIT | — |
| 离线二维码库 `assets/vendor/qrcodegen.js` | Project Nayuki QR Code generator | MIT（随插件附带许可证文本） | 固定摘要 |
| 连接器 cloudflared 2026.9.3（Windows AMD64） | Cloudflare 官方发布文件 | Apache-2.0 | 固定版本、固定字节数与 SHA-256；每次启动复验 |
| 自建中继 `scripts/relay_server.py` | 本仓库（随插件分发） | MIT | 纯 Python 标准库源码，无二进制可执行文件 |

- 连接器**可执行文件不随插件打包**：仅在用户明确同意后从官方地址下载到插件树外的运行目录（`KIMI_HOME/usage-dashboard/runtime/cloudflared/2026.9.3`），安装与每次启动都校验固定大小与摘要。
- **许可证文本随插件打包**，安装时先校验包内许可证（固定路径、拒绝符号链接或重解析点、校验大小与摘要），通过后才下载可执行文件；包内许可证缺失或损坏直接报 `CONNECTOR_HASH_MISMATCH`，不回退到网络获取。
- 实现为 Python ≥3.8 标准库，不新增 pip/npm 依赖。

## 3. 整体结构

```
桌面端 Kimi Code（侧栏注入）
  └─ 「手机」浮层（assets/kimi-remote-widget.js）
        │  仅回环地址 + 自定义控制头
        ▼
用量服务（scripts/service.py，本机回环端口 39281）
        │  /api/mobile/* 前置分流 → worker IPC 客户端
        ▼
mobile worker（scripts/mobile_worker.py，独立常驻子进程）
        ├─ scripts/mobile_bridge.py    配对 / 会话 / 受限 HTTP 代理 / WebSocket 隧道 / 限流
        ├─ scripts/mobile_usage.py     手机只读用量转发
        ├─ scripts/mobile_credentials.py  server.token 读取与自助补建
        ├─ scripts/mobile_security.py  共享受保护 DACL 原语
        ├─ scripts/mobile_tunnel.py    固定组件安装、校验、启动、停止（CF 隧道）
        └─ scripts/mobile_relay.py     RelayClient：自建中继隧道客户端（可断线重连）
        ▼
Cloudflare Quick Tunnel（仅出站连接） 或 自建中继 relay_server.py（VPS 侧，公网 IP）
        ▼
手机浏览器 → Kimi 原生手机单页应用（由桌面实例托管）
```

各层职责：

| 层 | 文件 | 职责 |
|---|---|---|
| 浮层界面 | `assets/kimi-remote-widget.js` | 同意勾选、安装、开启/停止、模式切换、二维码与配对链接、换发配对码、状态轮询、中继参数表单、旧通道提示 |
| 控制面适配 | `assets/kimi-mobile-api.js` | 浮层到后台的请求客户端：固定回环地址、自定义控制头、不带凭据、拒绝重定向、有限超时且不盲目重试 |
| 旧通道探测 | `assets/kimi-remote-api.js` | 官方中继接口适配层，当前仅用于探测旧版官方中继是否仍在运行 |
| 二维码 | `assets/kimi-remote-qr.js` + `assets/vendor/qrcodegen.js` | 离线生成二维码，无运行时外部依赖；失败时降级为可复制链接 |
| 浮层样式 | `assets/kimi-remote-widget-live.css` | 仅样式更新；不是通用脚本热重载 |
| 用量服务 | `scripts/service.py` | 用量采集与注入、模式滑杆、中继配置读写；`/api/mobile/*` 前置分流给 worker，模块缺失或异常时一律拒绝，不回退旧接口 |
| worker | `scripts/mobile_worker.py` | 进程隔离、IPC、状态记录与接管、权限收紧、启动阶段诊断 |
| 手机桥 | `scripts/mobile_bridge.py` | 配对码签发与兑换、会话 Cookie、精确方法与路由白名单代理、WebSocket 隧道（含心跳桥接）、桌面实例复核、限流 |
| 只读用量 | `scripts/mobile_usage.py` | 只从固定本机用量服务读取白名单字段并转发给已配对设备 |
| 凭据 | `scripts/mobile_credentials.py` | 读取/补建 `server.token`：拒绝软链与重解析点、原子不覆盖、受保护 DACL |
| 权限原语 | `scripts/mobile_security.py` | 共享受保护 DACL 设置；失败一律 fail closed |
| 隧道组件 | `scripts/mobile_tunnel.py` | CF 隧道固定组件安装、校验、启动、停止与进程隔离 |
| 中继客户端 | `scripts/mobile_relay.py` | `RelayClient`：连自建 VPS 中继，明文 ws/http，指数退避重连 + `X-Relay-Resume` 续期 |
| 中继配置 | `scripts/relay_config.py` | `<KIMI_HOME>/usage-dashboard/relay.json` 的读写与校验；token 只回 `token_set` |
| 中继服务端 | `scripts/relay_server.py` | VPS 侧（不参与本地运行）：隧道注册口 + 公网口，把手机请求封装成帧转发给 worker |

### 桌面接缝

- **注入顺序**：用量服务把固定顺序的资源同步到桌面资源目录并按摘要注入页面：二维码库 → 二维码桥接 → 旧通道适配 → 手机控制面适配 → 手机浮层；用量面板脚本始终最后。同步不完整的文件不注入，并会自动清理旧标签。
- **入口**：侧栏头部与最小化栏各有「手机」按钮，仅存在于桌面注入链内。
- **钩子**：清单的 4 个会话钩子统一走 `scripts/bootstrap.cmd`，只负责拉起与心跳用量服务，**不会自动开启手机连接**。

## 4. 配对与安全模型

### 4.1 配对

- 配对链接形如 `https://<随机名>.trycloudflare.com/mobile/pair#pair=<token>`；**配对码只出现在 URL fragment**，不进入 HTTP 请求、日志或浏览历史。
- 配对码**10 分钟有效、一次性**：成功兑换一台设备即销毁，同一张二维码不能连多台设备。
- **换发配对码**：浮层「生成新二维码」作废旧未用码并签发新码；已配对设备的会话、隧道与连接**不受影响**。
- 兑换落地页把 fragment 码同源提交，换取 **HttpOnly、SameSite=Strict 的会话 Cookie**；外网连接额外带 Secure。兑换有限速：同一来源短时间内多次失败会被临时禁止。
- 已配对会话再次进入配对页时直接进入应用，不消耗配对码。

### 4.2 设备会话生命周期

- 最多 8 台设备。
- **闲置 24 小时滑动过期**（只有真实已认证的活动才续期），**绝对寿命 7 天**，续期不超过绝对上限。
- Cookie 到期即失效；已建立的 WebSocket 由会话巡检按有界周期复查后切断。
- **停止即撤销**：清空全部配对码、会话与缓存，关闭监听与已建连接，停止隧道；worker 进程随之退出并清理记录与锁。

### 4.3 桌面实例复核

- 开启前核实目标桌面实例：注册信息中的地址与端口匹配，进程存活且为桌面客户端进程，进程创建时刻一致（防止进程号复用），相应端口的监听仍属于该进程，且健康检查通过。
- 运行中周期性多因子复核，判定策略为**连续 3 次失败才撤销连接**（`OWNER_LOST_GRACE`）：单次健康检查抖动只让当前请求失败，不拆隧道、不作废已配对会话。
- 已知取舍：身份检查保守，短暂探测失败会先让个别请求失败；连续失败最终仍会撤销连接。

### 4.4 凭据与数据边界

- **`server.token` 自助补建**：首次显式开启手机连接时，若 `~/.kimi-code/server.token` 缺失，桥会原子补建（`os.link` 不覆盖既有文件、先设受保护 DACL 再写入秘密、失败即中止且不留半成品）。读取侧拒绝软链/目录联接/重解析点，校验 inode+mtime+size，要求单行可打印 ASCII。失败回报 `SERVER_TOKEN_UNAVAILABLE`。
- **真实桌面凭据不出桥**：仅由桥在运行时读取，用于向上游注入授权头；不出现在 URL、Cookie、二维码、日志或响应里。手机端只持有无权限的占位值。
- **出向泄露体检**：每个响应体、响应头与 WebSocket 消息都检查是否出现凭据原文或其编码形态，命中即返回通用错误、不回显。
- 错误只使用有限错误码，不回传原始日志、运行目录路径或秘密链接。
- 限流分桶：匿名请求与已配对请求分别计数，避免匿名额度耗尽连带阻断正常已配对设备；限流命中返回 `Retry-After` 提示。

### 4.5 放行面（白名单）

手机侧请求实行**精确方法与路由白名单**，机器级与越权面默认拒绝：

- **只读面**：健康检查、元信息、模型、工作区、技能、工具、能力、搜索、媒体、认证、配置（原生已脱敏）以及会话列表。
- **会话读段**：会话下的已知只读子资源（消息、审批、提问、任务、文件历史、快照、状态等）。
- **会话写**：发消息/中止/引导、审批、回答问题、生成标题、任务取消或分离、文件系统只读动作，以及会话级的分叉、压缩、撤销、恢复、**归档、删除**，加上会话导出（`POST /sessions/{id}/export`，返回 ZIP）。批量归档/恢复另放行 `POST /api/v2/sessions:archive` 与 `:restore` 两条精确写动作。
- **全局配置写**：仅开放窄白名单键——默认模型、思考选项、自动会话标题、默认计划模式；空对象、未知键、重复键、危险键一律拒绝。
- **文件**：上传与下载。上传请求体上限 32 MiB（含包装开销）；仅精确上传路径的接收预算放宽为闲置 120 秒、累计最长 600 秒，其它路径保持较短预算。
- **静态面**：首页、索引页、站点图标、形状校验过的资源路径、会话管理页，以及单段的会话与设备路径；其余静态路径不转发。
- **一律拒绝**：终端、调试、关机、远程控制、权限、供应商、插件、MCP、OAuth、连接、运行时、机器级文件系统操作，以及原生未知子资源。归档/删除/导出**仅放行精确路径 + POST**，不做前缀匹配；对应 `GET` 版本仍拒绝。删除不可逆，归档可用恢复撤回。
- **WebSocket**：只向上游注入真实凭据，客户端仅回显占位子协议；消息按类型白名单过滤，终端类消息一律断开；同时连接数有界。

### 4.6 授权语义

扫码或打开配对链接即授予手机对当前电脑 Agent 的**会话面控制权限**：查看会话、发 prompt、审批、回答提问、上传与下载文件、归档/删除/导出会话。手机不能直连终端或机器级管理接口，但**这不消除控制电脑的风险**——请勿把配对链接或二维码交给他人。

## 5. 使用流程

### 5.1 内网模式

1. 在浮层模式切换块选择**内网**，挑一块本机 RFC1918 内网网卡，确认「明文 HTTP、仅可信 Wi-Fi」。
2. 生成 `http://<内网IP>:<端口>/mobile/pair#pair=…` 配对链接与二维码。手机须与电脑在同一可信 Wi-Fi。
3. 撤销：点「停止连接」——撤销全部配对、会话、WebSocket 与桥。

### 5.2 CF 隧道模式

1. 安装并启用插件，打开侧栏「手机」浮层。电脑需能访问 Cloudflare 与官方发布站点。
2. 勾选下载同意 → 安装连接组件（固定版本，首次可能需要 2–3 分钟，**安装中勿重复点击**）。安装成功后后续复用。
3. 单独勾选第三方中继同意 → 开启外网连接。**Cloudflare 在 TLS 终止处可见经过的会话内容**，安装同意不等于中继同意。
4. 等待隧道就绪；只有就绪且配对码有效时才显示链接与二维码。手机用**系统浏览器**扫码或打开链接（微信等内置浏览器请切换系统浏览器）。
5. 要给第二台手机配对：点「生成新二维码」重新扫码（旧码作废，已连设备不受影响）。
6. 撤销：点「停止连接」——撤销全部配对、会话、WebSocket 与隧道。

### 5.3 自建中继模式

1. 在自己的公网服务器上运行 `scripts/relay_server.py`（纯标准库，Python ≥3.8），指定隧道注册口、公网口与共享 token。**必须传 `--token`**：不传则注册口不校验，任何客户端都能接管隧道。
2. 在浮层中继表单填入服务器地址、隧道注册端口、公网端口与 token，保存后写入本机 `~/.kimi-code/usage-dashboard/relay.json`（读取不回显 token 明文）。
3. 选择**自建中继**模式开启：worker 以 `RelayClient` 连上 VPS 注册口，隧道就绪后签发配对二维码，手机入口为 `http://<服务器>:<公网端口>/t/<tid>/mobile/pair`。
4. 隧道断线会自动重连（指数退避 1s→30s，300s 后放弃），并用 `X-Relay-Resume` 复用 tunnel_id，已发出的配对地址在重连后仍可用。
5. **风险**：第一阶段为明文 `ws://` / `http://`，配对码、Cookie、会话与文件内容经 VPS 时不保密；服务器与本机各自配置同一把共享 token（仓库不内置默认值），请在部署时自行设定并妥善保管。仅在自控服务器、临时联调场景使用。
6. 撤销：点「停止连接」——撤销全部配对、会话、WebSocket 与隧道。

电脑须保持开机且桌面服务可用。CF 隧道需允许出站连接 Cloudflare（QUIC 或 TCP），不需要路由器入站端口映射；自建中继需要电脑能出站访问你的服务器，并在服务器放行注册口与公网口。插件不自动修改防火墙。**关闭浮层不会断开连接**；用量后台重启也不会中断已开启的手机连接（桥运行在独立 worker 进程中）。

## 6. 排障速查

| 现象 | 处理 |
|---|---|
| 「安装」按钮不可点 | 未勾选下载同意；旧版通道仍在运行（先显式停止）；或组件正在安装 |
| 安装失败 | 检查到官方发布站点的网络；等当前任务结束后显式重试；不要关闭 TLS 或安全软件绕过 |
| 摘要校验失败 | 包内许可证缺失/被改（重新安装插件），或运行目录中的组件被篡改（删除后重新安装） |
| 平台不支持 | 外网组件仅支持 Windows AMD64 |
| 隧道启动失败/超时/退出 | 检查网络是否允许出站连接 Cloudflare；插件不改防火墙、不需入站映射 |
| 二维码扫不出 | 用「复制链接」手动发送；改用系统浏览器 |
| 配对链接提示无效或过期 | 配对码 10 分钟过期或已被使用 → 点「生成新二维码」 |
| 手机端未授权或掉线 | 会话闲置超过 24 小时或超过 7 天绝对期限 → 重新生成二维码配对 |
| 手机端限流 | 命中限流，按提示稍后重试 |
| 手机端部分操作被拒 | 设计内拒绝：手机面是受限会话面，危险配置写不在白名单内 |
| 连接自动断开 | 桌面实例连续 3 次复核失败才停止；若仍断开，重新打开桌面端后再开启 |
| 提示"手机连接凭据"错误 | `server.token` 补建/读取失败（目录权限或软链）→ 检查 `~/.kimi-code` 权限与是否为符号链接 |
| 自建中继连不上 | 检查 `relay.json` 里的地址/端口/token；确认 VPS 上 `relay_server.py` 已用 `--token` 启动、注册口与公网口已放行 |
| 自建中继配对链接失效 | 隧道重连后 tunnel_id 通常经 `X-Relay-Resume` 复用；若服务器重启过，重新生成二维码 |
| 提示旧版本手机连接进程仍在运行 | 浮层点「停止」后升级；**不要**手动杀进程或重启电脑 |
| 传大图或大文件失败 | 上传接收预算已放宽，仍失败请检查是否超过 32 MiB 上限或上行带宽不足 |
| 面板显示离线 | 在实际安装目录重启用量服务 |
