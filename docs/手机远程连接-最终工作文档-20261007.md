# 手机远程连接 — 最终工作文档

> 版本 **v3.3.3（2026-10-08）**，GitHub Release 以 Pre-release 分发；手机远程连接为**预览功能**。
> 本文给出手机远程连接的最终口径：本版本范围、验证边界与**未验收清单**。
> 功能与安全模型见[手机远程连接-工作文档.md](手机远程连接-工作文档.md)；合并、生命周期与回滚见[手机远程连接-合并文档.md](手机远程连接-合并文档.md)。

## 1. 本版本范围（一句话摘要）

在用量面板侧栏加入「手机」浮层，用 Cloudflare Quick Tunnel 生成临时 HTTPS 配对链接与离线二维码，让手机在移动数据或其他 WiFi 下通过系统浏览器使用 Kimi 原生手机页面；手机桥运行在独立 worker 进程中，连接状态与用量后台解耦；另附手机只读用量页，以及一批连接、上传、权限、组件安装与界面稳定性修复。

手机远程连接为**预览功能**，接口与行为可能继续调整。

---

## 2. 行为要点

- **外网单一路径**：浮层只提供外网连接；旧版局域网或官方中继仍在运行时只显示提示与显式停止入口，不自动切换、不代为开关。
- **两段独立同意**：安装连接组件需明确同意；使用第三方中继需另行同意。打开浮层或查询状态不会安装组件、不会开启连接。
- **配对**：配对码 10 分钟一次性，只出现在链接的 fragment 中；可「生成新二维码」换发，不影响已连设备；停止即撤销全部配对、会话、WebSocket 与隧道。
- **会话**：闲置 24 小时滑动过期、绝对寿命 7 天、最多 8 台设备；关闭浮层不会断开连接。
- **独立 worker**：用量后台重启只 detach，已开启的手机连接继续存活；同版本新后台重连接管，旧版本 worker 不接管、不擅自结束，但放行显式停止。
- **手机只读用量**：已配对设备通过同源入口查看用量，只从固定本机用量服务读取白名单字段；用量服务不可用不影响聊天桥。
- **安全边界**：精确方法与路由白名单，未知路由与机器级接口默认拒绝；真实桌面凭据不下发手机；用户可控 HTML/SVG 强制 sandbox 与附件头；错误信息不回显秘密、原始日志或本机路径。
- **明确不承诺**：不是 P2P、不是端到端加密（Cloudflare 在 TLS 终止处可见转发内容）；Quick Tunnel 使用临时随机地址，不承诺永久链接或可用性 SLA。

## 3. 本版本的主要修复

| 领域 | 修复 |
|---|---|
| 连接与配置 | 全局配置写收窄为白名单键（默认模型、思考选项、自动会话标题、默认计划模式），危险键仍拒绝 |
| 限流 | 匿名与已配对请求分别计数，匿名耗尽不连带阻断已配对设备，保留重试提示 |
| 上传 | 修复 multipart 正文检查标记被误判为非法请求头；仅上传路径的接收预算放宽为闲置 120 秒 / 累计 600 秒（上限仍 32 MiB） |
| 上游异常 | 上游异常断开时返回受控错误，不再静默吞掉导致客户端长时间等待 |
| 进程隔离 | worker 使用 Windows 作业对象脱离标志隔离于用量后台；不能安全脱离时拒绝启动 |
| 权限 | 状态目录与凭据改为单次受保护权限写入，消除多步操作的中间空窗；失败即拒绝继续 |
| 启动诊断 | 启动失败区分状态目录、锁、进程创建、子进程退出、启动超时、版本不匹配等固定阶段 |
| worker IPC | 令牌失效时丢弃缓存句柄，下次重新核验，不自动重发写请求 |
| 组件安装 | 固定版本校验大小、摘要与随包许可证；下载瞬态失败有限重试；补齐 Python 3.8 超时异常识别，证书错误不重试 |
| 界面 | 浮层与模型弹窗视觉统一；窄屏二维码尺寸与暗色对比修复；键盘焦点循环；安装入口可恢复隐藏；状态查询失败仍可停止 |
| 更新保护 | 更新器增加本地预览自保护、完整性检查与手机运行文件保留，拒绝不完整组件组合 |

## 4. 验证现状（如实记录）

**已核实**：

- 固定版本连接器的真实标准安装成功（约 154 秒）；运行目录中的可执行文件与许可证大小、摘要复验正确；受控 `--version` 退出码 0。
- 桥、用量服务、前端资产与 worker 的多轮隔离环境测试通过（合成环境，未连公网、未读真实凭据）。
- 手机只读用量转发在隔离环境中验证：白名单取数、并发单飞、缓存降级、出口泄露体检、页面自包含。
- 维护期间的定点复跑为 **82 项执行通过**（含启动诊断、权限收紧、进程生成、前端请求生命周期、响应内容防护、请求体生命周期等分组）；另有指定维护用例 36 项复跑通过。

**口径说明**：

- 82 项与 36 项都是**执行计数**，不能相加当作项目测试总数，也不代表全项目去重测试全绿。
- 发布隔离回归迁移后 54 个检查项通过（33 个 Python 套件、9 个 Node 套件、12 项静态检查）。Python 记录 540 个用例，其中 2 个因符号链接权限跳过，另有 1 个被正向回归取代的历史观察用例未运行；Node 77 条断言通过。执行数包含继承重复，不是去重总数。
- 权限 API、启动阶段码、安装入口可恢复和发布版本合同已迁移；冻结历史审核包没有改写，不将其旧结果与本次结果混算。
- 隔离计数与状态接口返回正常都不替代真机与公网验收。

## 5. 部署与升级

- **升级方式**：安装本次发布文件（或按发布说明手动覆盖插件文件）。面板点「更新」按钮才会请求检查，发现新版本后弹窗显示发布时间与更新内容，**需点击确认**才会下载、覆盖插件文件并重启用量服务（用量数据、价格配置与桌面路径记录不受影响）。
- **预览形态**：带本地预览标记（清单 `localPreview: true` 或版本号带 `-local`）的安装会拦截在线自更新；从该形态迁移到本发布版本需按说明手动安装。GitHub 上发布的 `3.3.3` 清单为纯数字版本，不含预览标记；本发布源码与任何本机安装目录不承诺逐字节一致。
- 改动 Python 服务代码后，须在**实际安装目录**执行 `python scripts/service.py --restart`；仅改文档或样式无需重启。
- 手机连接开启时，用量后台重启不会中断连接；但桥本身变更须先「停止」手机连接让旧 worker 退出，再重新开启。

## 6. 安全提示

- **配对链接就是当前电脑 Agent 会话的控制授权**：手机可通过会话提示驱动 Agent 执行命令、读写文件。请勿分享二维码或链接。
- 手机不能直连终端或机器级管理接口；全局配置写仅限窄白名单键。
- 外网流量经 Cloudflare TLS 终止，Cloudflare 可见转发内容；用量采集仍在本机进行，开启外网聊天不等于所有流量纯本地。
- Quick Tunnel 使用临时随机地址，停止或重开后可能变化。

## 7. 未验收清单（不得当成已完成）

- **公网端到端**：真实手机经临时公网地址完成配对 → 会话 → 消息往返，执行者侧尚未完成回归（用户曾自报连通，用户报告不替代执行者验收）。
- **实体手机摄像头扫码**：截图解码验证不等于真机摄像头验收。
- **真实桌面界面的实际交互**：包括复制链接写入剪贴板、真实点击换发二维码等。
- **真实隧道完整生命周期**：启动、退出与进程回收全过程（受控 `--version` 通过不等于生命周期验收）。
- **手机端新建会话与真实消息往返**：仅隔离空会话检查通过，真实已有会话到首次发消息的完整链路未验收。
- **公网上传链路**：隔离环境字节一致；公网慢上传（含蜂窝上行）未验收。
- **真实桌面生命周期接管**：同版本 worker 重连接管与崩溃恢复在隔离环境验证，真实端到端未验收。
- **真实桌面进程隔离语义**：进程脱离标志只在合成环境中验证。
- **用户报告的失败图片**：未在真机复验；隔离测试只证明已修的合同本身。
- **超边界行为**：超大上传、请求头过慢等边界仍可能直接中止，不能承诺每种失败都显示完整友好的错误提示。
- **实例身份检查**：桌面实例身份检查偏严，短暂探测失败可能撤销连接；此项维护尚未完成。
