# Kimi Code 用量面板技能

## 数据读取

回答用量和成本问题前先读取最新数据，不凭空估算。可优先读取运行中服务，失败时尝试静态副本：

- `http://127.0.0.1:39281/api/usage`（仅查配额时用 `/api/quota`）
- `<Kimi Code 安装目录>/resources/desktop-dist/kimi-usage.json`
- 插件内的 `assets/kimi-usage.json`

汇报时标明更新时间；没有数据或数据过期时明确说明。

## 关键指标

| 指标 | 字段 | 解读 |
|---|---|---|
| 今日用量 | `today.tokens_fmt` / `today.calls` | 今日总 Token 与调用次数 |
| 输入与输出 | `today.in_fmt` / `today.out_fmt` | 输入包含缓存读取和缓存创建 |
| 今日成本 | `today.cost_fmt` | 按面板计价规则估算，不是账单 |
| 昨日/本周/本月/累计 | `yesterday/week/month/cumul.*` | 与今日同口径聚合 |
| 缓存命中率 | `cache.pct` | 缓存读取占总输入；≥70% 良好，40–70% 一般，<40% 时可检查长上下文是否反复送入 |
| 消耗速率 | `rate.tokens_per_hour` / `rate.cost_per_hour` | 最近 60 分钟实算，不是当日平均；异常升高时留意长会话或并发任务 |
| 输出速度 | `speed.tps` / `speed.model` / `speed.avg_tps` | 近 120 秒实时值、活跃模型和历史均值 |
| 当前模型 | `cur.alias` / `cur.effort` / `cur.sub_agent` | 当前会话在用模型与思考强度 |
| 本会话 | `session` | 本会话用量、调用次数、费用和缓存率 |
| 官方配额 | `quota.week` / `quota.h5` | `used/limit/pct/reset/pace/eta`；`null` 表示无数据，`pace > 1.3` 时提醒配速过快，有 `eta` 则给出预计耗尽时间 |
| 模型分布 | `today_models[]` / `cumul_models[]` | 按 Token 降序 |
| 会话排行 | `sessions[]` | 按 Token 降序，Top 8 |
| 小时分布 | `hourly[]` | 24 项，定位高峰 |
| 逐日明细 | `days30[]` | 最近 30 天 |

## 汇报模板

只展示用户所问的周期和指标。

```markdown
**Kimi Code 用量**（更新于 <updated_at>）

| 周期 | Token | 估算成本 | 调用次数 |
|---|---|---|---|
| 今日 | … | … | … |
| 本周 | … | … | … |
| 累计 | … | … | … |

- 缓存命中率：…%（缓存读取占总输入）
- 消耗速率（近 60 分钟）：… / 小时，折合 … / 小时
- 输出速度：… t/s（<model>）
- 周配额：已用 …%（配速 …×，重置 …）
```

## 面板与设置入口

- 侧边栏卡片 `Kimi Code 用量`：点「面板」或卡片标题打开全屏报表；点 `⚙` 打开设置中心，模型、供应商、MCP 服务器和技能均可搜索。编辑、技能正文和计价使用统一详情区；窄窗口返回列表保留位置。列表独立操作自动保存，表单点「保存」提交；未保存离开时应用内确认。
- 新增模型时，选供应商后手动获取列表，勾选并点「添加 N 个模型」，已有模型显示「已添加」；也可新建供应商后继续或手动添加。模型能力、上下文与强度在编辑中修改，计价、设默认和删除在「⋯」。设默认不会切换当前对话。
- 新模型默认识图、思考、工具全开，1M 上下文、五档思考与 `high`；可选 256k/1M 上下文预设或自定义。能力声明不代表上游实际支持。托管模型及被默认模型、子代理池、模式预设或恢复快照引用的模型不可删除，先解除引用。
- 编辑时供应商名称和模型别名固定，托管供应商只读。密钥默认保留，替换或清除须明确选择，不回显已有密钥；探测鉴权只在后台。
- 模型与供应商保存时严格解析 TOML，全量序列化后原子替换；保留未编辑字段值，不保留注释和原排版，不生成配置备份，不依赖 Kimi CLI。若配置被其他操作修改，重新载入再编辑；保存后可用 `/reload` 加载。
- 供应商卡片「⋯ → 删除供应商」确认后立即保存，连同旗下全部模型一起删除（确认框注明数量）。删除不受引用限制，相关默认模型、子代理池、模式档位/锁定/恢复快照引用会清理；托管/OAuth 供应商同样可删。删除移除本地连接和认证配置，不清除环境变量。不提供供应商重命名、复制、原始 TOML 编辑或备份恢复。
- MCP 高级选项默认折叠，保存后新会话或重连加载。技能仅用户级可编辑，关闭自动调用仍可手动触发，删除会移除整个目录。

## 挂件与档位

- 挂件开关在「面板」的设置里，默认开启。可从 `http://127.0.0.1:39281/api/settings` 的 `widgets_enabled` 确认当前状态，不根据历史提示推断。关闭后按宿主原生行为处理子代理，忽略历史挂件提示、白名单和锁档要求。
- 挂件开启时，「本对话」选档仅更新该对话的主模型和挂件白名单，并同步所需挂件；全局切档只影响跟随全局的对话。恢复跟随需在桌面卡片或手机面板点「本对话跟随全局」。关闭挂件后停用这些操作。
